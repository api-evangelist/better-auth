Better Auth 1.5 introduces an Auth CLI, MCP Auth, and an OAuth 2.1 Provider, plus Electron integration and i18n support. Other additions include adapter extraction, dynamic base URL, Cloudflare D1 support, a CLI init wizard, seat-based billing, SAML Single Logout, test utilities, and secret key rotation.
